# .NET Aspire 17 - .NET 10

## Projenin Temel Maksadı

.NET Aspire projesi, birden fazla .NET uygulamasının tek bir merkezden yönetilmesini, çalıştırılmasını, izlenmesini ve geliştirme süreçlerinin kolaylaştırılmasını sağlayan dağıtık uygulama geliştirme teknolojisinin öğrenilmesini amaçlamaktadır.

.NET 10 tabanlı projede .NET Aspire kullanılarak birden fazla ASP.NET Core Web API uygulaması tek bir AppHost üzerinden yönetildi. Aspire Dashboard aracılığıyla uygulamaların çalışma durumları, logları, environment değerleri ve telemetri verileri incelendi.

Proje kapsamında .NET Aspire'ın temel yapısı, AppHost kullanımı, proje entegrasyonu, servis yönetimi ve dağıtık uygulama geliştirme süreçleri ele alındı.
